# 최종 점검 — 내보내기 전에 이걸 통과해야 한다

빌드가 끝나면 아래를 위에서부터 확인한다. 하나라도 걸리면 고치고 다시 빌드한다.

## 내용
- [ ] 처음 보는 사람이 hero 만 읽고 "무엇을, 누구를 위해" 만든 건지 말할 수 있다
- [ ] 페이지 전체의 주 행동(primary CTA)이 **하나로 통일**되어 있다
- [ ] 지어낸 숫자·후기·로고가 없다 (없으면 그 섹션을 뺐다)
- [ ] 버튼 라벨이 전부 동사로 시작한다 ("자세히 보기" 없음)
- [ ] FAQ 가 진짜 반론을 다룬다 (편한 질문만 있지 않다)
- [ ] `[TODO]`, `여기에 내용`, `Lorem ipsum` 같은 자리표시자가 하나도 남아있지 않다

## 링크 · 동작
- [ ] 모든 `href` 가 실제로 존재하는 곳을 가리킨다 (`#` 만 있는 버튼이 없다)
- [ ] 앵커 링크(`#features` 등)를 클릭하면 해당 섹션으로 이동한다
- [ ] form 이 있으면 `action` 이 연결되어 있다 (또는 미연결임을 사용자에게 알렸다)
- [ ] 외부 링크는 `newTab: true`

## 보기
- [ ] 브라우저 창을 **375px 폭**으로 줄여도 가로 스크롤이 생기지 않는다
- [ ] 다크 모드에서도 글자가 배경에 묻히지 않는다 (우상단 토글로 확인)
- [ ] 이웃한 섹션의 배경색이 서로 달라 경계가 보인다
- [ ] 이미지에 `imageAlt` 가 다 채워져 있다
- [ ] 이미지 파일이 실제로 존재한다 (깨진 이미지 아이콘이 없다)
- [ ] 영상을 넣었다면 재생된다 (`file://` 에서 유튜브 오류 153 은 정상 — 웹에 올리면 재생됨)
- [ ] 팀원 사진·이름은 **본인 동의를 받고** 넣었다

## 인쇄 · PDF

- [ ] 브라우저에서 `Cmd/Ctrl + P` 를 눌러 미리보기를 보면 **모든 섹션이 나온다** (빈 페이지가 없다)
- [ ] 배경색이 필요하면 인쇄 옵션에서 "배경 그래픽"을 켠다

## 공유
- [ ] `meta.title` 이 60자 이하, `meta.description` 이 160자 이하
- [ ] `meta.favicon` 이 설정되어 있다
- [ ] 개인정보를 받는 폼이라면 수집 목적·보관 기간이 `note` 에 적혀 있다

## 확인 방법

```bash
python3 landing-page-kit/kit/build.py landing.json --open
```

`--open` 은 빌드 후 브라우저를 바로 연다. 창 크기를 좁혔다 넓혔다 하면서 위 항목을 훑는다.
